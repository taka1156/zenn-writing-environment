個人ブログでもそれっぽいOGPを作りたい人向け

## 背景・課題

ZennやQiitaをはじめとして、有名ブログサービスには記事内のリンクをOGPとして表示する機能があります。
これを自作で作れないかと思いHono + Litで作成してみました。

選定理由は以下になります。

- Hono
  - Cloudflare Workersで動かすといえばこれ
  - まだやっていませんが、ゆくゆくは、Honoのcache機能を使って毎回、取得処理が走ることを防ぎたい

- Lit
  - [marked](https://github.com/markedjs/marked)の置換処理内で単なるタグとして埋め込みやすい
  - jsを単体になるので、Cloudflare Workersのアセット設定で配信しやすい

### 環境・前提条件

- Dev Container (node v24 slimイメージ)
　ローカルで、Workers環境を動かすwranglerというライブラリがalpineだと動かないためこちらを利用

- ツール
  - biome  
    lint、フォーマッターツール
  - wrangler  
    ローカルでWorkers環境の動作確認を行うためのツール。
    それ以外にもデプロイなどのCloudflareの統合的なコマンドを扱える

### フロントエンド

markedで仕込む用のOGPタグのデザインとバックエンドとのフェッチ処理を内包したWeb Components定義を作成します。

|利用ライブラリ|役割|
|---|---|
|Lit|Web Componentsの定義をするためのフレームワーク|
|Vite|LibモードでES Modules形式のjsファイルにビルドするためのツールチェイン|
|[rollup-plugin-minify-html-literals](https://github.com/lit/lit/tree/main/packages/labs/rollup-plugin-minify-html-literals)|Vite単体ではCSSのminifyができない仕様だったのでこちらを適用してminify|

:::details vite.lib.config.tsの内容

```ts
     import minifyHTML from "@lit-labs/rollup-plugin-minify-html-literals";
     import { transform } from "esbuild";
     import { defineConfig } from "vite";

     export default defineConfig({
          root: ".",
          build: {
               outDir: "./assets/lib",
               emptyOutDir: true,
               minify: true,
               cssCodeSplit: false,
               lib: {
                    entry: "src/components/OGPCard/index.ts",
                    name: "OgpCard",
                    fileName: (format) => `ogp-card.${format}.js`,
                    formats: ["es", "umd"],
               },
          },
          plugins: [
               minifyHTML(),
               {
                    name: "minify-whitespace-only",
                    enforce: "post",
                    async generateBundle(_, bundle) {
                         for (const chunk of Object.values(bundle)) {
                              if (chunk.type === "chunk") {
                                   const result = await transform(chunk.code, {
                                        minifyWhitespace: true,
                                        loader: "js",
                                   });
                                   chunk.code = result.code;
                              }
                         }
                    },
               },
          ],
     });
```

:::

```jsonc
    "main": "src/backend/index.ts",
    // ...
    "assets": {
        "directory": "./assets",
        "binding": "ASSETS",
        "run_worker_first": true
    },
}
```

### markedへの統合

1. scriptの読み出し
     今回の場合、Next.jsを使っているのでオリジン部分を環境変数においています。
     また、next/scriptを使っています。

     ```html
          <Script
               src={`${process.env.NEXT_PUBLIC_OGP_BACKEND_URL}/lib/ogp-card.es.js`}
               type='module'
          />

     ```

2. [marked](https://github.com/markedjs/marked)にタグの置換処理を追加します。

:::details OGP置換処理

```ts
import type { MarkedExtension, Tokens } from 'marked';

interface OgpCardToken extends Tokens.Generic {
  type: 'ogpCard';
  url: string;
}

// 「(先頭 or 直前が空行) + URL + (直後が空行 or 末尾)」を要求する
const ISOLATED_URL_START = /(^|\n\n)(https?:\/\/[^\s<]+)[ \t]*(?=\n\n|\n?$)/;
const ISOLATED_URL_TOKEN = /^(https?:\/\/[^\s<]+)[ \t]*(?:\n(?=\n)|\n$|$)/;

const escapeAttr = (str: string): string =>
  str.replace(/&/g, '&amp;').replace(/"/g, '&quot;');

const markedOgpCard = (): MarkedExtension => ({
  extensions: [
    {
      name: 'ogpCard',
      level: 'block',

      start(src) {
        const match = ISOLATED_URL_START.exec(src);
        if (!match) return undefined;
        // グループ1(先頭 or "\n\n")の長さぶんずらして、URL自体の開始位置を返す
        return match.index + match[1].length;
      },

      tokenizer(src) {
        // 呼び出し時点で既に「ブロック境界」にいる前提なので ^ から始まればOK
        // ただし後方は「空行 or 文字列末尾」のみ許可(単一改行だけでは不可)
        const match = ISOLATED_URL_TOKEN.exec(src);
        if (!match) return undefined;

        const token: OgpCardToken = {
          type: 'ogpCard',
          raw: match[0],
          url: match[1]
        };
        return token;
      },

      renderer(token) {
        const t = token as OgpCardToken;
        const escapedUrl = escapeAttr(t.url);
        return `<div style="margin: 4px;"><ogp-card backend-url="${process.env.NEXT_PUBLIC_OGP_BACKEND_URL}/api/ogp" url="${escapedUrl}"></ogp-card></div>\n`;
      }
    }
  ]
});

export default markedOgpCard;
```

:::

```ts
  },
```

## 工夫した点

- Twitterカード向けのメタである`summary_large_image`がある時または、横長の比率（アスペクト比 1.2 以上）ある時は、ラージサイズのOGPデザインになるように調整
- Workersキャッシュを効かせて、1時間程度のキャッシュを取るように対応

## 苦労した点

- ZennのようにURL前後に空行がある時にOGP表示になるように設定しましたが、マークダウン記号があるときなど、細かいケースが対応できてないので調整中です。
